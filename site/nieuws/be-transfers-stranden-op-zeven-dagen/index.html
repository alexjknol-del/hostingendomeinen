Waarom .be-overdrachten zo vaak stranden op de termijn van zeven dagen

De transfercode van DNS Belgium is een week geldig. Dat is kort genoeg om een verkoop te laten mislukken die verder helemaal rond was.

Gepubliceerd op 14 mei 2026

Bij een verkoop van een .be-domeinnaam zijn twee handelingen nodig: de verhuizing tussen agents en de wijziging van de houder. De verhuizing verloopt met een transfercode die zeven dagen geldig is en eenmalig te gebruiken.

Zeven dagen klinkt ruim, tot een van beide partijen op vrijdag de code opvraagt, de tegenpartij op maandag reageert, er een vraag over de factuur tussendoor komt en de code op de dag van de overdracht net is vervallen. De code moet dan opnieuw worden aangevraagd, en in die tussentijd is het vertrouwen tussen partijen die elkaar niet kennen al aangetast.

De volgorde die werkt

  1. 01

    Alles afspreken voordat de code wordt opgevraagd

    Bedrag, betaalwijze, wie welke stap doet en op welke dag.

  2. 02

    Het geld eerst in escrow

    Zodat er geen discussie meer over de betaling loopt op het moment dat de klok van zeven dagen begint te lopen.

  3. 03

    De code opvragen en dezelfde dag doorgeven

    Niet op vrijdagmiddag, en niet vlak voor een vakantieperiode.

  4. 04

    De verhuizing binnen twee werkdagen uitvoeren

    Dat laat ruimte over voor een storing of een vraag.

  5. 05

    Daarna pas de houderwijziging

    Die is bij .be een aparte procedure met een eigen bevestiging.

Andersom kost een extra ronde

Wie eerst de houder wijzigt en daarna de code opvraagt, moet die code opnieuw aanvragen omdat de gegevens zijn veranderd. Dat is geen storing maar de bedoeling van het systeem.

De informatie over de transfercode staat bij DNS Belgium op https://www.dnsbelgium.be/en/transfer-code. De procedure voor een houderwijziging staat op https://www.dnsbelgium.be/en/manage-your-domain-name/change-holder.
