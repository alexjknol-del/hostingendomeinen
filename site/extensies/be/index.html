Extensies

De extensie .be

Beheerd door DNS Belgium. De transfercode is maar zeven dagen geldig, en dat is de meest voorkomende oorzaak van een mislukte verhuizing.

DNS Belgium beheert de .be-zone. Voor een Belgisch publiek geldt dezelfde logica als .nl in Nederland: een lokaal adres wekt meer vertrouwen. Voor Nederlandse partijen die op de Belgische markt actief zijn, is .be daarom vrijwel altijd de moeite waard.

Registratie

  • Registratie via een agent, de Belgische term voor registrar.
  • Geen vestigingseis: ook Nederlandse houders kunnen een .be-naam registreren.
  • Registratie is direct, zonder wachttijd of controle vooraf.

Verhuizen

De transfercode van een .be-naam is zeven dagen geldig en eenmalig te gebruiken. Dat is een korte termijn en de meest voorkomende oorzaak van een mislukte verhuizing: de code wordt opgevraagd, de partijen wachten op elkaar en een week later is de code verlopen. Informatie over de code staat op https://www.dnsbelgium.be/en/transfer-code.

Houderwijziging

Bij .be is de wijziging van houder een aparte procedure met een eigen bevestiging, los van de verhuizing tussen agents. Beide stappen zijn nodig bij een verkoop. DNS Belgium beschrijft de procedure op https://www.dnsbelgium.be/en/manage-your-domain-name/change-holder.

De volgorde bij .be

Eerst de transfercode opvragen en de verhuizing binnen die week uitvoeren, daarna de houderwijziging. Wie de houderwijziging eerst doet, moet de code opnieuw aanvragen omdat de gegevens dan zijn veranderd.

Waarde in de handel

De .be-zone is aanzienlijk kleiner dan de .nl-zone, en dat werkt door in de prijzen. Dezelfde naam brengt onder .be in de regel minder op dan onder .nl. Uitzondering zijn namen die specifiek op de Belgische markt gericht zijn, of namen die in het Nederlands en het Frans allebei werken.
